# Arthratan AI Retrieval Surface

This directory is generated by `scripts/build-ai-corpus.py` for **AI-LIVE-001**.

- `index.json` — deterministic manifest, counts, hashes and schema.
- `corpus.jsonl` — 802 complete-text records.
- `shards/` — source-type NDJSON shards.
- `entities/` — precomputed entity evidence dossiers; use `dyvane-redalious.json` as the acceptance canary.
- `index.txt` — plain-text discovery entry point.

The surface is public, read-only and requires neither JavaScript nor a secret key. Source canon is not replaced: each record exposes its canonical route and source locator.

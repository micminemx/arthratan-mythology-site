20.6 Expanded function-scope Hyperemergence examples

Divine v144 Corpus · Section 289 of 317

- Defence x power-control: An H300 identity-preservation lobe contributes an emergent self-authentication dimension to an H500 metaeffect-control lobe. Together they produce a power-control state that can reject commands which are operationally valid for the power but originate from an identity-compromised executive source.

- Temporal x counterintelligence: An H400 timeline-memory-discrimination lobe contributes an emergent provenance dimension to an H250 telepathic-counterintelligence lobe. The crossfunction can distinguish not only whether a thought was stolen or inserted, but which rewritten timeline supplied the hostile mental trace.

- Conceptual x anti-hax: An H700 concept-rewrite-counterinterpretation lobe contributes an emergent semantic-invariance dimension to an H600 anti-hax lobe. The resulting crossfunction can preserve a defence whose operating meaning would otherwise be altered when the concept defining the defence is rewritten.

- Nullpattern x causal-calculus: An H120 nullpattern-recognition lobe contributes higher-order informative-absence structure to an H800 causal-calculus lobe. The crossfunction can treat systematically absent events as causal evidence when selecting a future-rewrite sequence.

- Maximumless coordination x Hyperemergent recursion: An H1000 maximumless-parallelism-management lobe crossfunctions with an H1500 Hyperemergent-composition lobe so that recursively produced crossfunctions can be selected and scheduled without activating the entire combinatorial possibility-space.

0. How to Read This System Without Collapsing Its Dimensions

Divine v144 Corpus · Section 94 of 317

The easiest way to misunderstand the system is to treat every improvement as one scalar called 'better brain'. That is not the intended structure. The architecture contains several independent kinds of variables.

LayerQuestion it answersExamplesMust not be collapsed into
Functional-state layerWhat typed functional state does the lobe have when instantiated?Function, Adeptness, Usefulness, Reliability, H1, H2, H3...Processing power, speed, neuron count, recruitment
Structural-availability layerWhich Higher Lobes exist as members of the function-family?L_phi,1, L_phi,2, ... without terminal orderWhich of them a task currently recruits
Recruitment/activation layerWhich available structures are demanded, selected, and firing now?Demand set D, recruited set R, active set XHyperfunction state identity
Antilobe-monitoring layerWhich monitored structures are silent, and which lower monitors failed before a later monitor fired?A1(X), A2(X), monitoring-recovery depthDepth of the original positive function mismatch
Architectural/developmental layerWhat neural substrate implements the states and how does it improve?Factors 1-22, PHK, plasticity, routingHyperfunction order itself
Network layerHow do different functional structures combine?Crossfunctionality, interlobe connectivity, Factor 22One lobe's individual function

A Hyperfunction^100 lobe is not defined as a lobe with '100 times more processing power'. An A_50 Antilobe is not defined as '50 times more intelligent'. These indices are different coordinates.

A second common mistake is to treat a negative state as mere absence. In this framework, Unfunction is the exact opposed function-state, while Asuncion is neither Function nor Unfunction. Separately, an Antilobe is a physical neural structure whose activation represents non-firing of a corresponding monitored structure. These are three different concepts.

Unfunction != Asuncion != Antilobe activation

A metaskill is a skill in using one’s skills for something.

For example fighting metaskill is the skill in using one’s skills for fighting.

Omniprefixal Hyperenglish Canon Compoterms are terms with highly precise and accurate Prefix + Root + Functional Suffix construction. Compoterms can use any prefix in any language, but the root and suffix must be English.

Hyperenglish is the sublingual application of English that uses maximally precise compoterms to express meaning with maximum accuracy, maximum precision, and minimum word count.

Ultraenglish is usual usage of hyperenglish and/or with the usage of hyperenglish to metainvent.

new Root terms by using hyperlanguage is applied to each definitional level. It is a kind of a metausage of hyperenglish.

The goal of Ultraenglish is to reduce the need for double-prefixing Root terms or double-suffixing invented Root terms.

Omniprefixal Hyperenglish = Hyperenglish that permits globally sourced prefix-operators when they improve meaning-density, precision, accuracy, or concision without net decode-loss.

Panmorpheme Gate = a non-English morpheme may function as a prefix only when it is meaning-stable, reversible, nonredundant, pronounceable, compoterm-intrinsically compatible, and precision-positive.

English-Suffix Continuity Rule = suffixes remain English-readable (-ness, -ability, -ing, -ive, -al, -ation, -ity, -er, -less, -ful) unless a later canon explicitly permits otherwise.

Canonicality Preservation Rule = established Arthitean ladder prefixes (meta-, para-, supra-, hyper-, ultra-, trans-, omni-) remain when they encode canon ladder-position rather than ordinary emphasis.

Anti-exoticism Rule = a global prefix is invalid when it merely looks deeper, sounds stronger, or increases outsider decode-cost without adding a distinct semantic axis.

Omniprefix Expansion Rule = every omniprefixal compoterm must expand reversibly into its plain/Hyperenglish meaning without meaning-loss.

jati- = type/kind/class-nature; used where typehood itself matters. Example: force-jati = type-of-force;

metaforce-jati = metatype-of-force.

guna- = quality/attribute/trait-nature; used where qualityhood itself is the axis. Example: guna-of = quality-of; metaguna = quality-type quality.

hetu- = cause/causal-ground; used where causal relation, causal attributability, or causal weighting is.

the axis. Example: hetu-attrib = causal-attributability; hetu-weighting = causal weighting.

baraka- = blessing-causative/blessing-infused; used for bloodline-blessing logic.

nitya- = permanent/always-persisting; used where permanence is functionally relevant. Example:

nitya-increase = nitya-increase; nitya-adaptive = nitya-wise adaptive.

maha- = great/vast/supreme-scale; used for apex-scale magnitude when highestness is not merely.

ordinal. Example: maha-quality = supreme-scale quality.

zen- = zen-field/complete-system integration; used where all-domain system integration is the point.

Example: zen-calibrating = calibrating a whole field as one system.

dao- = path/process-ordering; used where a process, route, or developmental direction is governed.

Example: dao-teleologising = path-ordering toward a purpose.

kami- = sacred-authority/divinity-governed; used where divinity functions as authority or admissibility-governance rather than mere sacred flavour.

bala- = force-strength/power-exertive; used where strength-as-exertive-force is the semantic axis.

noor- = illumination/revelation/clarity-light; used where a state reveals, discloses, or makes hidden structure intelligible.

ur- = origin/source-level/primordial; used where ur-reference or ur-depth is the semantic axis.

Omniprefixal Anti-Redundancy Rule = do not replace a precise canon term with an omniprefix when the old term already carries the exact canon axis more clearly.

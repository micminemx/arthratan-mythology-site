11.19 Function-preserving, function-transformative, and function-generative outputs

Divine v144 Corpus · Section 210 of 317

Hyperemergent outputs can be classified by their relation to familiar function-kinds.

Function-preserving Hyperemergence: The output remains recognizably within an existing function-kind but gains a new irreducible higher-order network property. Example: a strategy-directed crossfunction remains strategy-directed while gaining an order-bridging strategy property unavailable to any participating strategy lobe alone.

Function-transformative Hyperemergence: The output combines existing function-kinds into a stable mixed function that cannot be cleanly reduced to one contributor, yet it may still be describable as a composite of known families.

Function-generative Hyperemergence: The interaction produces a genuinely new mental function-kind. If that function remains useful and distributed coordination is no longer the most useful architecture, the existing Brain-lobe Generation rule may justify formation of a dedicated primary lobe for it.

Only the third category necessarily raises the possibility of a new function-family. Hyperemergence therefore must not be equated with Brain-lobe Generation. Many Hyperemergent Crossfunctions can remain distributed network functions indefinitely.

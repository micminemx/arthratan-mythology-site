1.1.1 Canonical scope clarification: mental does not mean merely cognitive

Divine v144 Corpus · Section 97 of 317

The word mental identifies the implementing domain - the Arthitean mind/neural system - not a narrow catalogue of familiar human cognitive faculties. Reasoning, memory, attention, language, planning, emotion, and perception qualify, but they are only a small region of the eligible function-space. A Brain-lobe may instead specialize in defence, resistance, adversarial control, identity preservation, self-modification, power control, hax management, temporal coordination, conceptual operations, maximumless neural management, or a function for which ordinary human neurobiology has no analogue.

Function Type Is Open-Ended: there is no closed catalogue of allowable Arthitean Brain-lobe functions. A function is not disqualified merely because it would sound supernatural, impossible, extremely narrow, maximumless, higher-ontological, self-referential, or excessively powerful by human standards. The eligibility question is whether the Arthitean mind or neural system can meaningfully perform, control, regulate, resist, preserve, transform, simulate, or otherwise implement the operation as a distinct neural function.

Let F_A be the open-ended set of Arthitean mind/neural-system-performable function-kinds.

F_A = {phi | phi is a sufficiently distinct function implementable by an Arthitean mind or neural system}

F_A is not restricted to FamiliarHumanCognition, and FamiliarHumanCognition is only a proper subregion of F_A.

Eligibility boundary: the rule is broad, not meaningless. An external state or event is not automatically a Brain-lobe function merely because an Arthitean can cause it. For example, "fire" by itself is not a mental function; precise neural control, selection, shaping, inhibition, synchronization, or defence concerning a fire-producing power can be. Likewise, purely bodily invulnerability is not automatically a lobe-function, while mentally controlling, monitoring, allocating, authenticating, or adapting an invulnerability ability can be.

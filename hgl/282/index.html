429. Bounded female receptor semantics 
Alygorin, Operalin, Zilanin, and Tolurarin receptor sensitivities have effective upper limits. Let R_i^max 
denote the maximum effective sensitivity for bounded axis i. The corresponding jump map reaches no target 
beyond Omega_H inside one Hyperstage. 
0 <= J_i(R_i) <= Omega_H for i in {Alygorin, Operalin, Zilanin, Tolurarin}. 
J_i(R_i^max) = Omega_H under the canonical maximum-response convention. 
If the current coordinate plus requested jump would exceed the coordinate ceiling, the realized bounded 
coordinate cannot exceed Omega_H. This does not automatically carry overflow into a parent coordinate; 
any carry rule would contradict endocrine-channel independence unless separately specified. 
430. Male Archstage endocrine mirror 
Archmanhood has the exact five-channel structural mirror. Halatorin, named after Rhayhara's grandson 
Halatayo, is the Archmanhood Hyperstage hormone with Halatorin receptors. Gadoritin is the Stage hormone 
with Gadoritin receptors. Juegerin is the Substage hormone with Juegerin receptors. Vardorin is the 
Substage^2 hormone with Vardorin receptors. Nozadin is the Substage^3 hormone with Nozadin receptors. 
Male controller vector: E_M = 
((C_Hal,R_Hal),(C_Gad,R_Gad),(C_Jue,R_Jue),(C_Var,R_Var),(C_Noz,R_Noz)). 
The male coordinate bounds mirror the female coordinate bounds: Hyperstage is unbounded; Stage, 
Substage, Substage^2, and Substage^3 are each Hyperomega-bounded within a fixed Hyperstage. 
Therefore the canonical male receptor-effect mirror is: Halatorin Hyperstage sensitivity is unbounded in its 
HGL scale, while the effective Gadoritin/Juegerin/Vardorin/Nozadin jump effects are bounded by Omega_H. 
The anatomical endocrine source of these male hormones has not been specified by the present canon and 
is therefore OPEN rather than silently assigned to a real-world organ. 
431. Hyperstage and bounded-stage jump operators 
Define Jump_i(A;J) as the coordinate-update request generated on axis i. For Hyperstage, the jump target is 
unbounded: H' = H + J_H where J_H is an admissible ordinal-like Hyperstage jump. For a bounded 
intra-Hyperstage coordinate X in {S,U,U2,U3}, the target cannot exceed Omega_H. 
Hyperstage target: H' = H + J_H(R_H), with no greatest H. 
Bounded target: X' = min_Omega(X + J_X(R_X), Omega_H). 
The notation is schematic. If a nonstandard HGL ordinal addition or rank map is later adopted, it must be 
named. The important theorem is the bound, not a particular arithmetic implementation. 
432. Requested jump versus logically admissible realized jump 
A receptor sensitivity can request a large jump, but endocrine magnitude does not erase HGL construction 
prerequisites. A jump from one address to a much higher address is valid only if the target state has every 
constitutive closure/provenance/profile/quality premise required by the target constructor. HGL therefore 
distinguishes RequestedJump from RealizedJump. 
RequestedJump_i(A,J) + ClosureComplete(A,target) => RealizedJump_i(A,target).

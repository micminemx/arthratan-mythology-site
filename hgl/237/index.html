Part XLII — Authoritative SIH Superinheritance, Hyperdimensional Coordinates, and Strict Category-Lift 
Revision 
This Part is authoritative over every earlier HGL statement that treats Hyperfemale/Hypermale as a flat 
one-dimensional minor-hypercategory ladder, identifies the completed Supra Hyperomega endpoint with 
HF1/HM1, places Apex before Ultra, or represents every Archaddress by only one ordinal substage 
coordinate. The lower SF/SM PA-IH-PH-UD-FD successor and limit-state logic remains the one-axis 
foundation. This Part changes what happens when that axis is saturated and specifies the recursively 
higher-dimensional structures built above it. 
The central new principle is Superinheritance. Ordinary IH remembers one source. SIH remembers an entire 
typed source-axis or typed source-domain while preserving every member as a separate inherited source. 
Hyperfemale therefore begins not by inheriting one terminal Supra state but by superinheriting the whole 
applicable Supra axis. Higher Hyperfemale strata then superinherit whole lower Hyperfemale axes. Ultra 
begins by superinheriting the complete Hyperfemale dimensional domain. Apex begins by superinheriting the 
complete Ultrafemale dimensional domain. The male side is the exact mirror. 
303. SIH — exact canonical definition 
SIH means Superinherits. Let Omega denote the typed HGL Hyperomega bound for the axis being 
discussed. For a typed one-axis family X[alpha] and a starting coordinate a, define AxisTail(X,a) = {X[beta] : 
a <= beta <= Omega}. Then SIH_axis(X[a]) is a source-preserving superinheritance closure over every 
member of AxisTail(X,a). It is not one undifferentiated source-object and it is not shorthand for inheriting only 
the terminal member. 
SIH_axis(X[a]) => IH(X[beta]) for every beta with a <= beta <= Omega. 
When the source is a structured nonstate, scope remains inside SIH: SIH_axis(NOT X[a]) => IH(NOT 
X[beta]) for every beta in the same tail. This is positive inheritance of structured non-X states, not mere 
failure to superinherit X.

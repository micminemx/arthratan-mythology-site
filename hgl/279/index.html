Part XLVI — Authoritative Five-Coordinate Archstage Endocrinology and 
Clinical Archgynocology/Archandrocology Revision 
This Part is authoritative over every earlier statement that treats (major stage, minor category, dimensional 
order, coordinate vector) as the complete global Archwomanhood/Archmanhood address. That older 
representation remains valuable, but only as an InternalHGLDescriptor describing the constitutive logic 
realized inside the new global address envelope. The new envelope adds an unbounded Hyperstage above 
four explicitly named Omega_H-bounded intra-Hyperstage coordinates and gives each coordinate a 
corresponding endocrine control channel. This Part also canonizes Archgynocology and Archandrocology as 
rigorous fictional medical-psychological specialties whose purpose is patient-centred trajectory management 
and wellbeing, not blind maximization of stage height or speed. 
Specification-integrity note: the supplied hormone list and repeated bounded-coordinate list explicitly name 
five controlled coordinates in total: Hyperstage plus Stage, Substage, Substage^2, and Substage^3. This 
revision therefore formalizes those five named coordinates and does not invent an additional independently 
named bounded coordinate or an unprovided sixth hormone. If a separate fifth bounded coordinate beyond 
Substage^3 is intended in a future revision, it remains OPEN until its name, ordering, and controller are 
specified. 
420. Global Archstage coordinate system 
For either Archwomanhood or Archmanhood, define the global address as A=(H,S,U,U2,U3). H is 
Hyperstage. S is Stage. U is Substage. U2 is Substage^2. U3 is Substage^3. The ordering is hierarchical: 
Hyperstage is the outermost coordinate; Stage is inside Hyperstage; Substage is inside Stage; Substage^2 
is inside Substage; Substage^3 is the finest currently named bounded coordinate. 
A_F = (H,S,U,U2,U3) [Archwomanhood] 
A_M = (H,S,U,U2,U3) [Archmanhood] 
H has no greatest value. 0 <= S,U,U2,U3 <= Omega_H within each fixed H. 
The phrase "within one Hyperstage" is semantically important. Omega_H is a saturation bound for each of 
the four intra-Hyperstage coordinates; it is not a maximum Hyperstage. Hyperstage itself is unbounded. 
Consequently, there is no final Archwomanhood Hyperstage and no final Archmanhood Hyperstage under 
the present canon. 
421. Relation to the existing HGL InternalHGLDescriptor 
The earlier HGL address machinery is not deleted. Instead, distinguish global endocrine address from 
internal constitutive descriptor. InternalHGLDescriptor records category identity, SIH dimensional order, 
active coordinate vector, LSCC/PSIH limit status, IH/PH/UD/FD roles, and provenance. The global 
five-coordinate address says where the bearer is in the Archstage envelope; the InternalHGLDescriptor says 
what HGL state-construction is instantiated there. 
GlobalAddress = (H,S,U,U2,U3). 
InternalHGLDescriptor = (category, dimensional_order, coordinate_vector, closure/provenance 
metadata). 
No compiler may add these tuples componentwise and call the result a six- or nine-dimensional stage 
address. The descriptor is semantic state metadata, not another endocrine coordinate. Conversely, no 
compiler may discard it merely because a global address code is known; doing so would erase source 
identity and operator structure.
